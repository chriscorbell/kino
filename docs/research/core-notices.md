# Core WASM and retained shell notices

The reviewed inventory contains 133 Cargo packages from Core's WebAssembly build graph, the Rust 1.95.0 standard library notice set, and the retained Stremio shell GPL notice. All 135 entries have notice files. The local artifact index records 255 files and their SHA256 hashes. Files and extraction details are in [the committed review manifest](../../third_party/notices/reviewed.json); source archive hashes and graph limits are in [its Core provenance record](../../third_party/notices/reviewed.json).

## Source and build identity

The npm registry reports `@stremio/stremio-core-web` 0.61.0 at git commit `474ffaa42e0b7b9bcba0dd99368c41e828579dec`. Its published WASM has SHA256 `9dfa4fca8881331a019215eb987a31a01a99bf3414d1f67fe0830d3b15408b7e`. The registry metadata is saved in `build/license-research/core/npm-provenance.json`. [Published package metadata](https://registry.npmjs.org/@stremio%2fstremio-core-web/0.61.0), [pinned source](https://github.com/Stremio/stremio-core/tree/474ffaa42e0b7b9bcba0dd99368c41e828579dec).

Upstream's build script invokes `wasm-pack build` for the web target without changing Cargo features. The package defaults to `std` and `wasm`; its `stremio-core` dependency enables `derive` and `analytics`. The inventory uses that package, target, and feature configuration with the committed lockfile. [Build script](https://github.com/Stremio/stremio-core/blob/474ffaa42e0b7b9bcba0dd99368c41e828579dec/stremio-core-web/scripts/build.sh), [package manifest](https://github.com/Stremio/stremio-core/blob/474ffaa42e0b7b9bcba0dd99368c41e828579dec/stremio-core-web/Cargo.toml), [lockfile](https://github.com/Stremio/stremio-core/blob/474ffaa42e0b7b9bcba0dd99368c41e828579dec/Cargo.lock).

The selection command was:

```sh
cargo tree --locked --target wasm32-unknown-unknown \
  -p stremio-core-web --edges normal,build --prefix none --format '{p}' \
  --manifest-path <pinned-source>/Cargo.toml
```

This produced 133 unique name/version pairs. A metadata-only traversal produced nine additional inactive optional packages, so it was discarded for selection. The saved `cargo-tree.txt` determines the inventory; `cargo-metadata.json` supplies package paths, repository URLs, and license declarations. Normal and build edges include host procedural macros and build dependencies conservatively. Dev-only packages are excluded.

This is an inventory of the pinned source build graph. It does not establish which functions survive release LTO and `wasm-opt`. JavaScript package notices, including Babel runtime, belong to the separate npm inventory. The source's release profile enables LTO and size optimization, and its web package configures `wasm-opt`. [Release profile](https://github.com/Stremio/stremio-core/blob/474ffaa42e0b7b9bcba0dd99368c41e828579dec/Cargo.toml), [WASM optimization settings](https://github.com/Stremio/stremio-core/blob/474ffaa42e0b7b9bcba0dd99368c41e828579dec/stremio-core-web/Cargo.toml).

The index records the immutable archive URL, the Cargo.lock checksum, the original path within the archive, and each copied file's SHA256. Nested notices are retained, including `regex-syntax/src/unicode_tables/LICENSE-UNICODE` and `tracing-core/src/spin/LICENSE`. Copyright and authors files are retained where present.

## Rust standard library

The shipped WASM's `producers` section identifies `rustc 1.95.0 (59807616e 2026-04-14)`, `walrus 0.26.1`, and `wasm-bindgen 0.2.121 (49457f2db)`. Rust's 1.95.0 tag resolves to `59807616e1fa2540724bfbac14d7976d7e4a3860`, matching the compiler identity. The standard library is outside Core's Cargo.lock. [Rust 1.95.0 source](https://github.com/rust-lang/rust/tree/59807616e1fa2540724bfbac14d7976d7e4a3860).

The inventory retains `LICENSE-MIT`, `LICENSE-APACHE`, and `COPYRIGHT` from the official `rust-std-1.95.0-wasm32-unknown-unknown` distribution. It also retains `COPYRIGHT-library.html` from the official `rustc-1.95.0-aarch64-apple-darwin` distribution. Both archive hashes were checked against their published `.sha256` files. [Rust standard library archive](https://static.rust-lang.org/dist/rust-std-1.95.0-wasm32-unknown-unknown.tar.xz), [standard library checksum](https://static.rust-lang.org/dist/rust-std-1.95.0-wasm32-unknown-unknown.tar.xz.sha256), [compiler archive](https://static.rust-lang.org/dist/rustc-1.95.0-aarch64-apple-darwin.tar.xz), [compiler checksum](https://static.rust-lang.org/dist/rustc-1.95.0-aarch64-apple-darwin.tar.xz.sha256).

Rust documents `COPYRIGHT-library.html` as its aggregation of standard-library source and third-party notices. This supplies notices for runtime code absent from Core's dependency graph, including allocator and compiler built-in components. Its platform coverage is broader than WebAssembly. A readable `COPYRIGHT-library.txt` extracts the HTML body, decodes character entities, and collapses repeated blank lines; the original HTML remains available for comparison. [Rust's copyright explanation](https://github.com/rust-lang/rust/blob/59807616e1fa2540724bfbac14d7976d7e4a3860/COPYRIGHT).

The aggregation names two additional in-tree license exceptions without reproducing their full texts. The inventory also retains the pinned source's `Unicode-3.0.txt` and `BSD-2-Clause.txt` alongside the original copyright attributions in the aggregation. [Unicode license](https://github.com/rust-lang/rust/blob/59807616e1fa2540724bfbac14d7976d7e4a3860/LICENSES/Unicode-3.0.txt), [BSD license](https://github.com/rust-lang/rust/blob/59807616e1fa2540724bfbac14d7976d7e4a3860/LICENSES/BSD-2-Clause.txt).

## Retained shell provenance

Kino records the shell integration as a GPL-3.0-only fork at `c3a8bcbf857d5569b6ae7444ead0dc0a0814888b`. The notice inventory retains that revision's complete `LICENSE.md`. Its `mpv.cpp` and `mpv.h` have no separate copyright headers to recover. This entry covers the retained player integration described by Kino; it does not claim that Stremio's full shell is bundled. [Kino's provenance record](../../apps/macos-shell/UPSTREAM.md), [pinned upstream license](https://github.com/Stremio/stremio-shell/blob/c3a8bcbf857d5569b6ae7444ead0dc0a0814888b/LICENSE.md), [mpv.cpp](https://github.com/Stremio/stremio-shell/blob/c3a8bcbf857d5569b6ae7444ead0dc0a0814888b/mpv.cpp), [mpv.h](https://github.com/Stremio/stremio-shell/blob/c3a8bcbf857d5569b6ae7444ead0dc0a0814888b/mpv.h).

No selected package remains without a recovered notice. The remaining limits are inventory precision after optimization and the intentionally broad standard-library notice set. This research does not evaluate the separate source-distribution obligations of the finished application.
