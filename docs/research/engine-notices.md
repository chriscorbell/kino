Reviewed streaming engine notice artifacts are in `build/license-research/engine/`. This collection supplies the missing license texts and embedded native notices needed by issue #68. It leaves app code, package scripts, dependency versions, and license declarations unchanged.

`reviewed-registry-index.json` contains 54 selected registry packages whose package roots lack license files. `reviewed-native-index.json` contains six stream-server package entries, UnRAR and 7-Zip notices, and three supplements for native code inside `-sys` crates. `own-package-gap.json` records Kino's separate package/repository declaration mismatch. Every referenced artifact has a source URL and SHA256. The 174 file references resolve to 256,514 bytes of distinct artifacts, all verified against their recorded hashes on September 5, 2026.

The engine's resolved Cargo metadata contains inactive optional dependencies. Walking every normal dependency edge produced 642 packages, including Skia. The actual selected tree contains 543 distinct package/version pairs, including Kino itself. The collection uses this command to select packages:

```sh
cargo tree --locked --manifest-path apps/stream-engine/Cargo.toml \
  --target aarch64-apple-darwin -e normal --prefix none --format '{p}'
```

The selected tree is saved at `/tmp/kino-engine-actual-tree.txt`. The settings GUI disables Slint's default features and selects `backend-winit` and `renderer-femtovg`. `skia-bindings`, `skia-safe`, and `i-slint-renderer-skia` do not occur in that tree, and no native Skia build artifacts were present. Their optional Cargo metadata entries do not justify a Skia notice for this build. `tiny-skia` remains selected and belongs in the generic crate collector. [The pinned settings GUI manifest](https://github.com/stremio-native/stream-server/blob/f585ab6eda9b1411034548c131bb0dc30c6f5f9e/settings-gui/Cargo.toml), [Cargo tree documentation](https://doc.rust-lang.org/cargo/commands/cargo-tree.html).
