Reviewed streaming engine notice artifacts are in `build/license-research/engine/`. This collection supplies the missing license texts and embedded native notices needed by issue #68. It leaves app code, package scripts, dependency versions, and license declarations unchanged.

`reviewed-registry-index.json` contains 54 selected registry packages whose package roots lack license files. `reviewed-native-index.json` contains six stream-server package entries, UnRAR and 7-Zip notices, and three supplements for native code inside `-sys` crates. `own-package-gap.json` records Kino's separate package/repository declaration mismatch. Every referenced artifact has a source URL and SHA256. The 174 file references resolve to 256,514 bytes of distinct artifacts, all verified against their recorded hashes on September 5, 2026.

The engine's resolved Cargo metadata contains inactive optional dependencies. Walking every normal dependency edge produced 642 packages, including Skia. The actual selected tree contains 543 distinct package/version pairs, including Kino itself. The collection uses this command to select packages:

```sh
cargo tree --locked --manifest-path apps/stream-engine/Cargo.toml \
  --target aarch64-apple-darwin -e normal --prefix none --format '{p}'
```

Since patch 0008, Kino depends on stream-server without its `tray` feature, which leaves out upstream's tray icon and Slint settings window along with tao, winit, and their platform crates. The selected tree for this target fell from 543 to 417 package/version pairs, and the supplements for the Slint, Lyon, profiling, and older objc2 crates were removed with them. Linux loses the most: the tray pulled in GTK 3, Wayland, and X11 bindings. [Cargo tree documentation](https://doc.rust-lang.org/cargo/commands/cargo-tree.html).

For registry packages, `.cargo_vcs_info.json` supplies the exact upstream revision. The collection downloads that revision's license documents, preserves their bytes, and records original manifests as declaration evidence. Shared repositories account for most omissions: objc2, JNI, and autocxx keep license documents above their individual crate directories. The index preserves separate package versions and source revisions even when their texts have identical hashes. [Cargo's package VCS metadata format](https://doc.rust-lang.org/cargo/commands/cargo-package.html#cargo_vcs_infojson-format), [an example pinned Lyon license](https://github.com/nical/lyon/blob/56219c95c658d4f39de7b190d98e57d5773ba241/LICENSE-MIT).

Newer objc2 releases use a repository `LICENSE.md` that states the crate-specific choices and links standard license texts. That document is retained. Separate files from SPDX license-list-data 3.26.0 supply the full declared MIT, Apache-2.0, and Zlib texts. The index labels those files `standard-license-reference`, which distinguishes them from project-specific upstream notices. [objc2's pinned declaration](https://github.com/madsmtm/objc2/blob/7b1abfd750a2cacaea71d6a56ecfb83cb7de560b/LICENSE.md), [SPDX 3.26.0 license texts](https://github.com/spdx/license-list-data/tree/v3.26.0/text).

The six stream-server project crates share the root MIT license, including its `Copyright (c) 2025 perpetus` notice. That license does not replace the separate notices for vendored UnRAR and 7-Zip. `async-sevenz` and `enginefs` have no package-level license field, so their entries identify the actual repository-level document rather than claiming Cargo declared MIT. [The pinned stream-server license](https://github.com/stremio-native/stream-server/blob/f585ab6eda9b1411034548c131bb0dc30c6f5f9e/LICENSE).

UnRAR's version header identifies 7.11, dated March 20, 2025. Its full bundled license is copied verbatim, including Alexander Roshal's copyright and the restriction concerning creation of RAR-compatible compression. [The vendored UnRAR version](https://github.com/stremio-native/stream-server/blob/f585ab6eda9b1411034548c131bb0dc30c6f5f9e/bindings/async-rar/vendor/unrar/version.hpp), [the separate UnRAR license](https://github.com/stremio-native/stream-server/blob/f585ab6eda9b1411034548c131bb0dc30c6f5f9e/bindings/async-rar/vendor/unrar/license.txt).

7-Zip's vendored header identifies 25.01. Comparison with official commit `5e96a8279489832924056b1fa82f29d5837c9469` found 646 identical files after CRLF normalization. Only `CPP/7zip/Bundles/LzmaSpec/LzmaSpec.cpp` differs; `async-sevenz/build.rs` does not compile it. `7zip-comparison-normalized.json` records that comparison. The collected `DOC/License.txt`, `DOC/copying.txt`, and `DOC/unRarLicense.txt` preserve the complete upstream notice and LGPL text. The compiled extraction subset uses LGPL 2.1 or later and public-domain source declarations. The RAR, LZFSE, Zstd, and XXH64 files named as exceptions by the full notice are outside this build script's source list. [The pinned 7-Zip notice](https://github.com/ip7z/7zip/blob/5e96a8279489832924056b1fa82f29d5837c9469/DOC/License.txt), [the actual extraction build list](https://github.com/stremio-native/stream-server/blob/f585ab6eda9b1411034548c131bb0dc30c6f5f9e/bindings/async-sevenz/build.rs).

The native supplements also preserve `aws-lc/LICENSE` and `aws-lc/third_party/fiat/LICENSE` from `aws-lc-sys` 0.44.0, `c_src/mimalloc/v3/LICENSE` from `libmimalloc-sys` 0.1.49, and `zstd/LICENSE` plus `zstd/COPYING` from `zstd-sys` 2.0.16+zstd.1.5.7. The mimalloc build output points to the v3 include directory, whose header reports 3.3.2. These files supplement the Rust wrapper's root license files. [AWS-LC's component notice](https://docs.rs/crate/aws-lc-sys/0.44.0/source/aws-lc/LICENSE), [mimalloc's native license](https://docs.rs/crate/libmimalloc-sys/0.1.49/source/c_src/mimalloc/v3/LICENSE), [Zstd's native notice](https://docs.rs/crate/zstd-sys/2.0.16%2Bzstd.1.5.7/source/zstd/LICENSE).

The remaining declaration gap is Kino's own helper. `apps/stream-engine/Cargo.toml` declares MIT, but the directory contains no license text or `license-file` setting. The repository's root `LICENSE` contains GPL version 3. `own-package-gap.json` preserves both exact files and their hashes. This research does not change either declaration or supply an invented MIT copyright notice. [The helper manifest](../../apps/stream-engine/Cargo.toml), [the repository license](../../LICENSE).
