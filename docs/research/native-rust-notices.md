# Native Rust runtime notices

The installed native compiler is Homebrew Rust 1.98.0, commit `88d9e12ae178fab0fb5cc050a94da85685d449ea`, for `aarch64-apple-darwin`. The engine's saved Cargo compiler record in `build/engine-target/.rustc_info.json` identifies the same compiler. `rustc --print sysroot` returns `/opt/homebrew/Cellar/rust/1.98.0`. These command results are saved in [the provenance record](../../build/license-research/rust-native/provenance.json).

Homebrew provides the root `LICENSE-MIT`, `LICENSE-APACHE`, and `COPYRIGHT` files. Its standard-library aggregation is at `<sysroot>/share/doc/rustc/COPYRIGHT-library.html`. The installed file is only 4,021 bytes and has an empty out-of-tree dependency section. File existence alone would therefore leave the native runtime's third-party notices incomplete.

The matching official compiler archive supplies a complete 1,512,520-byte aggregation with 142 third-party entries. The recovered archive's SHA256 is `287edbc2e285b9c23ef7b085413b90cb8539909eda9c4b49f2a55ec0b52819d4`, matching Rust's published checksum. Its aggregation covers the standard library across targets and is conservatively broader than the macOS runtime. [Official Rust 1.98.0 compiler archive](https://static.rust-lang.org/dist/rustc-1.98.0-aarch64-apple-darwin.tar.xz), [published checksum](https://static.rust-lang.org/dist/rustc-1.98.0-aarch64-apple-darwin.tar.xz.sha256).

The seven-file [notice index](../../build/license-research/rust-native/index.json) retains the original root notices, complete `COPYRIGHT-library.html`, a readable text extraction, and the additional in-tree Unicode and BSD license texts. The extraction decodes HTML entities and collapses repeated blank lines; the original remains available for comparison. The in-tree aggregation preserves the associated copyright attributions. [Pinned Unicode license](https://github.com/rust-lang/rust/blob/88d9e12ae178fab0fb5cc050a94da85685d449ea/LICENSES/Unicode-3.0.txt), [pinned BSD license](https://github.com/rust-lang/rust/blob/88d9e12ae178fab0fb5cc050a94da85685d449ea/LICENSES/BSD-2-Clause.txt), [Rust's explanation of its copyright aggregation](https://github.com/rust-lang/rust/blob/88d9e12ae178fab0fb5cc050a94da85685d449ea/COPYRIGHT).

An offline collector can locate the compiler through `rustc --print sysroot`, then read the root notices and try `share/doc/rustc/COPYRIGHT-library.html` for Homebrew or `share/doc/rust/COPYRIGHT-library.html` for Rust's official distribution layout. It must reject an empty out-of-tree section and require reviewed fallback notices for the exact compiler version. It should also retain full texts for the in-tree exceptions named by the aggregation. The native inventory's version must follow the native compiler; Core's embedded WASM separately identifies Rust 1.95.0.
