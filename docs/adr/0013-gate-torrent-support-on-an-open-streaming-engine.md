# Gate torrent support on an open streaming engine

Torrent sources identified by an `infoHash` are required before Kino calls a release 1.0 or fully Stremio-compatible. Early macOS development may connect to a separately installed Stremio Service, but official Kino packages will not redistribute an ambiguously licensed streaming blob. Kino will audit and prototype the open Rust `stream-server` as a pinned, replaceable component on desktop and Android TV. It must stream original media without software video transcoding and pass functional, security, licensing, and resource-use review before Kino bundles it.
