# Render video as SDR without software decoding

Kino's initial releases will output SDR only. When hardware can decode an HDR10, HLG, Dolby Vision, or other 10-bit source, Kino will tone-map the decoded frames to SDR on the GPU rather than passing HDR metadata to the display. Kino will test Dolby Vision profiles 5, 7, and 8 as inputs and reject any profile that cannot produce correct SDR frames. Kino will reject software-only video decoders because their resource cost and playback quality are unpredictable. Unsupported codecs, profiles, and failed tone mapping return the user to source selection with a clear reason. Audio decoding, lossless audio handling, and stereo downmixing remain separate supported paths. Display refresh-rate matching will be available where the platform supports it but disabled by default on every platform.
