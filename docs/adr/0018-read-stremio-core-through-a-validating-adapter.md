# Read Stremio Core through a validating adapter

Kino reads every Core model through pure adapters in `apps/desktop/src/core/adapters.ts`. The worker runs them immediately after `core.get_state`, then adds Kino's paging status and add-on transport annotations, so nothing past the worker sees a serializer payload. `CoreStateMap` binds each model name to the state its adapter returns; transport and `useCoreModel` infer the state from the model key, so a caller cannot ask for the wrong shape.

The adapters take `unknown` and check every field the application consumes before building typed data. Serializer spellings stay inside them: Discover deep links become `CatalogRequest | null`, Library options become `LibraryRequest` values derived from the option and the current selection, `_id` becomes `id`, and Core's `announce` becomes the application's `sources`. A source variant is chosen from its identifying field rather than from `url`, because Core's Player output adds its own streaming-server URL beside `infoHash` and `ytId`. Manifests and profile settings carry their complete serialized record so install, uninstall, and settings updates round-trip fields Kino never displays.

A payload that contradicts the contract raises `CoreContractError`, which names the model and field path and never repeats the offending value. It rejects the read and flows through existing model error handling instead of reaching a click handler or a playback action. An ordinary provider failure is not a contract error: `Err` stays `Err` so a failed catalog is still distinguishable from an empty one, and a well-formed source Kino cannot play stays visible with an explanation.

Type-only fixes have passed before while contradicting the pinned serializer, so `pnpm check` runs `scripts/check-core-contract.mjs`. It reads live state from the pinned WASM, passes it through the production adapters, and asserts the application values. The committed fixtures under `apps/desktop/src/core/fixtures/` come from `scripts/capture-core-fixtures.mjs` and are regenerated, not edited.
